Zoi Restaurant is a luxury digital experience crafted for Ranchi's most sophisticated dining destination. This website combines cinematic visuals with high-performance interactions to reflect the premium atmosphere and culinary excellence of Zoi.

## ✨ Key Features

- **Cinematic Hero Experience**: An immersive, auto-playing gallery with smooth clip-path transitions and character-by-character title animations.
- **Ultra-Smooth Interaction**: Integrated with **Lenis** for high-end inertial scrolling and **GSAP** for fluid, physics-based animations.
- **Global Culinary Journey**: Interactive sections highlighting Asian, Italian, Continental, and Mediterranean specialties.
- **Premium Design System**: A sophisticated Navy & Gold aesthetic built on top of **Shadcn UI** and **Tailwind CSS**.
- **Responsive Excellence**: Fully optimized for a seamless experience across mobile, tablet, and desktop viewports.
- **Interactive Gallery & Menu**: Dynamic displays for the restaurant's ambience and signature dishes.

## 🛠️ Tech Stack

- **Core**: React 19, TypeScript
- **Build Tool**: Vite 7
- **Styling**: Tailwind CSS, PostCSS
- **Animations**: GSAP (GreenSock Animation Platform), ScrollTrigger
- **Scroll Engine**: Lenis (Studio Freight)
- **UI Components**: Shadcn UI (Radix UI primitives)
- **Forms**: React Hook Form, Zod

## 🚀 Getting Started

### Prerequisites

- Node.js (v20 or higher recommended)
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone [repository-url]
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

### Building for Production

To create an optimized production build:
```bash
npm run build
```

## 📂 Project Structure

- `src/sections/`: Modular page sections (Hero, Menu, Philosophy, etc.)
- `src/components/`: Reusable UI components (Headers, Footers, Shadcn primitives)
- `src/hooks/`: Custom React hooks for state and animation logic
- `src/lib/`: Utility functions and library configurations (utils, gsap-setup)
- `src/index.css`: Global styles and Tailwind directives
